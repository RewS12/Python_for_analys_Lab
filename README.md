# Лабораторная работа №1 — Продвинутый NumPy

## Что внутри

В этой работе я разобрал 5 задач по продвинутому NumPy:

- Посмотрел, как `float32` и `float64` теряют точность и что такое машинное эпсилон
- Попрактиковался в индексации, срезах и broadcasting
- Разобрался с memory-mapped файлами и тем, как порядок обхода массива (по строкам или столбцам) влияет на скорость из-за кэша процессора
- Поработал с разреженными матрицами (CSR, COO, CSC) и сравнил их с плотными
- Написал функцию суммы квадратов на чистом Python и на Cython, чтобы замерить реальный прирост скорости

## Как запустить

Чтобы всё это запустить, сначала нужно поставить библиотеки:

python setup.py build_ext --inplace
