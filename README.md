Лабораторная работа №1 — Продвинутый NumPy
В этой работе я разобрал 5 задач по продвинутому NumPy. Посмотрел, как float32 и float64 теряют точность и что такое машинное эпсилон. 
Попрактиковался в индексации, срезах и broadcasting. 
Разобрался с memory-mapped файлами и тем, как порядок обхода массива (по строкам или столбцам) влияет на скорость из-за кэша процессора. 
Поработал с разреженными матрицами (CSR, COO, CSC) и сравнил их с плотными. /
Ну и напоследок написал функцию суммы квадратов на чистом Python и на Cython, чтобы замерить реальный прирост скорости.
Как запустить
Чтобы всё это запустить, сначала нужно поставить библиотеки:
pip install numpy scipy cython
Потом скомпилировать Cython-часть командой:
python setup.py build_ext --inplace
После этого просто запускаем основной файл:
python lab1_numpy.py
Структура проекта
lab1_numpy.py — основной файл со всеми задачами
sum_of_squares.pyx — Cython-код для 5 задачи
setup.py — скрипт для сборки Cython-расширения
test_array.dat — memory-mapped файл (создается автоматически при запуске, добавлен в .gitignore)
